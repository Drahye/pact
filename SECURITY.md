# Security policy

## Reporting a vulnerability

Email **security@pact.africa** with the details and steps to reproduce. Please don't open a public issue for security problems. We aim to acknowledge reports within two working days and to keep you updated until the issue is resolved.

Please don't access other people's data, move money you don't own, or degrade the service while testing. Research done in good faith within these limits won't be pursued.

## Scope

- The web app and API in this repository.
- The payment, webhook, authentication and ledger code paths are the highest priority.

## Design

The controls and threat model are described in the Security section of the [README](README.md#security).
